# VOLT — Studio Capillaire (React + Vite)

Direction cyberpunk / next-gen : Orbitron + Rajdhani + JetBrains Mono,
duotone magenta/cyan, glitch effects, grille néon en perspective.

## Installation
```
npm install
npm run dev
```

## Build de production
```
npm run build
```

Projet de démonstration réalisé dans le cadre d'un portfolio.
Le formulaire de réservation simule l'envoi (aucune requête réseau réelle).
